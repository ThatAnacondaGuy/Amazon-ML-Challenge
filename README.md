# Amazon ML Challenge

A machine learning project focused on business entity resolution:
identifying records that refer to the same real-world entity across
different data sources.

## Repository contents

- `code/business_entity_resolution/` — source code, pipeline modules,
  requirements, tests, and execution scripts.
- `design_probes/` — experiments and diagnostic scripts.
- `student_resource/utils/` — submission validation utility.
- `SOLUTION_PLAN.md` — solution planning notes.
- `Documentation_template.md` — documentation template.
